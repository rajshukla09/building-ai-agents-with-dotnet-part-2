# Instructor notes

Start with `GET /api/mcp/tools` and point out that descriptions and schemas originate in each server adapter. Submit “What open authentication problems are being tracked?”—the request does not name GitHub, yet the model can select the issue-search function from its advertised meaning. Then use the Contoso/project prompt and follow the sequence logs to show that the second choice occurs after the first result. Disable a server in configuration to demonstrate genuinely dynamic availability. Emphasize that the model decides, while policy validates and limits.
